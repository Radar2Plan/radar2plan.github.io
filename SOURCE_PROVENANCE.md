# Source provenance

The standalone project page preserves the Radar2Plan research page from
`YaoLING1111/YaoLingHomePage` at commit `faa75c624af0a91fdbabd55dc3301a3375e078ef`.

Source components: `src/components/research/Radar2PlanPage.astro`,
`ConditionResults.astro`, `DemoGallery.astro`, `radar2plan-data.ts`,
`radar2plan-demos.ts`, `radar2plan-conditions.json`, and `radar2plan.css`.

The original repository's GNU AGPL v3 LICENSE is retained verbatim.
Figures and curated web videos remain credited to Radar2Plan in source metadata;
removing the redundant visible footer sentence does not remove provenance.
Design inspiration: https://lecar-lab.github.io/FADA-humanoid/.

Media files are obtained from the pinned public source commit and verified by
Git blob SHA-1 and file length before inclusion in a Pages deployment artifact.
Videos are not committed to this website source repository.
The anonymous manuscript PDF is excluded: paper links use arXiv:2610.06121.

Local changes: remove the independent top/footer personal-home links; use
verified author links; update the public preprint resources and BibTeX; add
scholarly metadata; publish at the standalone site's root rather than
`/radar2plan/`. Evaluation data, demos, and page design are preserved.
